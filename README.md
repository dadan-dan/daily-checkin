# daily-checkin

每天自动在 GitHub 上留下一条打卡记录。

## 它做什么

每天北京时间 09:00，GitHub 的服务器会自动启动一台临时虚拟机，往 `checkin/log.txt` 追加一行当天的日期，然后推送回仓库。

- 不需要本机开机 —— 跑在 GitHub 的机器上
- 不需要任何服务器或密钥 —— 用仓库自带的临时令牌
- 连续提交会在个人主页的贡献图上形成绿点

## 文件说明

```
.github/workflows/daily-checkin.yml   定时任务的定义
checkin/log.txt                       打卡记录，一行一天
```

## 手动触发

进仓库页面 → **Actions** → 左侧选 `Daily Check-in` → 右上角 **Run workflow**。

## 改打卡时间

编辑 `daily-checkin.yml` 里的 cron 一行。**注意时间是 UTC，北京时间要减 8 小时**：

| 北京时间 | cron |
|---|---|
| 07:00 | `0 23 * * *` |
| 09:00 | `0 1 * * *` |
| 21:00 | `0 13 * * *` |

## 注意事项

- 仓库必须设为 **Public**，私有仓库的提交默认不计入贡献图
- 仓库连续 60 天无任何活动，定时工作流会被 GitHub 自动停用
- 定时触发可能有几分钟到几十分钟的延迟，偶尔会跳过
